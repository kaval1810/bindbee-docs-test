---
title: "Logs"
description: "Real-time visibility into the requests and responses behind a connector - the first place to look when a sync misbehaves."
---

Logs give you real-time visibility into your API request and response data, so you can see exactly what happened for a particular connector.

Each entry shows the direction of the data - `READ` or `WRITE` - along with the request and the response it received. When a response is an error, the error code is shown alongside it.

<Tip>
  This is the first place to look when you want to know whether an integration is
  working.
</Tip>
