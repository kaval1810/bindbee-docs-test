Coverage is a property of the **integration**, not the vendor - two variants of the same brand can return different models. This page answers one question only: *does this integration return this model at all?*

<Warning>
  **Data needed** — every cell below is `·`, meaning not yet published. The rows and columns are correct and complete: 69 integrations pulled from [Integration & Coverage](/get-started/integrations), and all 44 models across the three categories, pulled from `spec.json`. Send the support data and the tables fill in place.

  {/* VERIFY: no endpoint returns model support per integration. /api/v1/lookup/models is per category, and /api/v1/lookup/integrations returns an integration's categories, not its models. So this page is hand-maintained and will drift silently the moment a connector gains a model. Worth asking whether coverage can be exposed on the lookup endpoint - Finch backs its Field Support tool with data for exactly this reason. Until then, this page needs an owner and a review cadence. */}
</Warning>

## How to read this

| Symbol | Means |
| --- | --- |
| **✓** | The integration returns this model |
| **—** | The integration does not return this model |
| **·** | Not yet published |

Three things this page deliberately does not tell you.

**It is not field level.** A ✓ means the model is returned, not that every field on it is populated. Systems differ in which fields they expose, and a model can arrive with most of it empty.

**It is not per connector.** [Scope](/get-started/scoping) is set per organisation and the source system's own permissions apply on top, so a specific customer can be missing a model this page marks ✓.

**It is not a write matrix.** Read support and write support are separate - see [What you can write](/guides/reading-writing/meta-apis).

<Info>
  To find what one **specific** connector actually returns, query it — see [Check a connector's actual coverage](/get-started/integrations#check-a-connectors-actual-coverage). That is authoritative in a way a published table cannot be.
</Info>
