The Model Context Protocol is an open standard that lets an AI assistant call tools and read documentation from an external source. Bindbee exposes an MCP server so an assistant can answer questions about the API against current documentation rather than whatever it was trained on.

## What you can use it for

Once connected, an assistant can answer questions grounded in these docs - which endpoint returns terminated employees, what `RELINK_NEEDED` means, why a field is missing - without you pasting documentation into the conversation.
