Creating a Custom Field from the dashboard takes two steps: create the field, then map it. For the concepts see the [Custom Fields overview](/guides/extending/custom-fields). For the programmatic route see [API Configuration](/guides/extending/custom-fields/api-workflow).

## Step 1: Create the field

Click **New Field** in the top right, fill in the dialog, then click **Create**.

  **Screenshot needed** — Custom Fields list page with the "New Field" button highlighted in the top right. Upload to `new-field-button.png` on the documentation image host, then replace this callout with a `<Frame>` captioned "Create a new custom field from the Custom Fields page."

<Note>
  Names must be **unique** within the model and follow **snake\_case**.
</Note>

## Step 2: Configure mappings

You are redirected to the mapping screen, where you can set up **Connector Level** and **Organization Level** mappings for the field.

<Warning>
  **Screenshot needed** — Mapping configuration screen showing the Connector Level / Organization Level toggle. Upload to `mapping-screen.png` on the documentation image host, then replace this callout with a `<Frame>` captioned "The mapping screen, with both scope options."
</Warning>

| | Connector Level | Organization Level |
| --- | --- | --- |
| Applies to | One connector instance | Every connector of that integration |
| Select from dropdown | Your connector | Your integration |
| Then fill the data field | Three options below | Three options below |

Fill the **Data field** box in any of three ways:

<CardGroup cols={3}>
  <Card title="Pick from options" icon="list">
    Select a mapping from the suggested list.
  </Card>

  <Card title="Browse raw JSON" icon="code">
    Click `</>` to open the raw response, then click the field you want.
  </Card>

  <Card title="Type the path" icon="keyboard">
    Enter the JMESPath expression directly.
  </Card>
</CardGroup>

<Warning>
  **Screenshot needed** — Raw JSON panel opened via the </> button, with a field being clicked to map it. Upload to `raw-json-viewer.png` on the documentation image host, then replace this callout with a `<Frame>` captioned "Click the `</>` button to browse the connector's raw response and select a field."
</Warning>

<Info>
  Add multiple mappings to a single custom field with **Add New**, repeating the process for other connectors or integrations.
</Info>

<Warning>
  An incorrect JMESPath does not raise an error. When you request `custom_fields` through the API, the response returns `"INVALID_JSON_PATH"` for that field instead of the value.
</Warning>

## Find fields using Employee Search

A field may not exist for every employee. Sometimes it only appears in the `raw_data` of one. Employee Search shows live connector data so you can locate it while configuring the mapping.

<Steps>
  <Step title="Open the search">
    Click the employee search field at the top of the data panel.
  </Step>

  <Step title="Find the employee">
    Enter a name or email address, then select the right result.
  </Step>

  <Step title="Map the field">
    Review the raw data in the right hand panel, select the field you want, then click **Map Field**.
  </Step>
</Steps>

<Warning>
  **Screenshot needed** — Employee search box at the top of the data panel with results showing. Upload to `employee-search.png` on the documentation image host, then replace this callout with a `<Frame>` captioned "Search for an employee to load their live connector data."

<Note>

</Note>
