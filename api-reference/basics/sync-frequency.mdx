---
title: "Sync Frequency"
sidebarTitle: "Sync frequency"
description: "How often a Production connector syncs, and how to change it."
---

A Production connector syncs **every 24 hours**. The schedule is set per connection, so one customer can sync on a different schedule from another.

Need a different frequency, or a specific start time? Contact [support@bindbee.dev](mailto:support@bindbee.dev) with the connector IDs and what you need — neither is a dashboard control today.

<Note>

</Note>
