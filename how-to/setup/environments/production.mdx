## Overview

The Production environment is used for running live customer integrations. It handles real customer data and is intended for use with customers actively operating in production.

Connectors, their data, and logs are isolated from Development - but scope and custom field configuration are shared across both environments.

<Warning>
  Production API keys provide access to real customer data. Keep them secure and never expose them publicly.
</Warning>

See [Environments](/how-to/setup/environments/overview) for what's shared vs. separate between Development and Production, plus how to manage and authenticate with your key.

## Production API Key

Your Production API key (`prod_api_key`) is used exclusively to access the Production environment. It cannot be used to access the Development environment.

<Note>
  Only Production API keys can be used to access the Production environment.
  Development API keys are strictly limited to the Development environment.
 </Note>

## Sync Behavior

In the Production environment, data syncs are handled automatically.

<Note>
  Data synchronization occurs once every 24 hours by default. This sync frequency can be adjusted based on customization preferences.
</Note>

## Intended Usage

The Production environment is designed for:
- Live customer integrations
- Real-time and scheduled data synchronization
- Stable, production-ready workflows

It should only be used once integrations have been fully tested in the Development environment.
